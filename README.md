# augur-skills

Curated skills marketplace for [Claude Code](https://docs.anthropic.com/en/docs/claude-code).

## Quick Start

```bash
/plugin marketplace add simpleapps-com/augur-skills
/plugin install simpleapps@augur-skills
/plugin install simpleapps-statusline@augur-skills
```

| Plugin | What it gives you |
|--------|-------------------|
| `simpleapps` | SimpleApps development workflow: skills, commands, rules, output styles, MCP servers |
| `simpleapps-statusline` | Two status lines under the prompt (a mod, Claude Code 2.1.287+). See [its README](plugins/simpleapps-statusline/README.md) |
